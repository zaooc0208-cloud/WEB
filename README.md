## 🌟 平台特色與核心功能

1. **原考卷 11 題錯題專攻（目標：奪回 44 分！）**
   * 針對在考卷上答錯的題目（第 2, 3, 7, 10, 12, 13, 17, 19, 20, 22, 24 題）提供高亮提示。
   * 包含：原卷作答選項、正解、失分關鍵原因與防陷阱解析。

2. **全卷 25 題互動測驗**
   * **💡 即時解題模式**：每點選選項即刻得知對錯，立即展開詳細觀念剖析與 A/B/C/D 各選項破題分析。
   * **⏱️ 考場模擬模式**：計時答題、全卷 25 題作答完後統一交卷結算評分，並產生成績單與弱點分析。
   * **⭐ 題目收藏功能**：重要或易混淆題目隨手按星號收藏，可單獨篩選複習。

3. **核心考點精華講義**
   * **電腦五大單元**：CU（控制）、ALU（算術邏輯）、MU（記憶）、IU（輸入）、OU（輸出）架構對比。
   * **記憶體階層速度天梯**：暫存器 > 快取 (SRAM) > 主記憶體 (DRAM) > SSD > HDD。
   * **半導體對比表**：SRAM vs DRAM（速度、電路、刷新、用途）。
   * **ROM 演進史**：Mask ROM ➔ PROM ➔ EPROM ➔ EEPROM（悠遊卡、RFID）➔ 快閃記憶體。
   * **儲存與周邊技術**：SSD 為何千萬不能磁碟重組？熱插拔開機關機皆可拔、AMOLED 有機發光二極體、Line-out 音效輸出埠。

4. **🎴 抽認翻牌記憶卡**
   * 3D 翻轉問答卡片，包含高頻考點秒殺口訣。
   * 支援掌握度標記與進度追蹤。

5. **🖼️ 原始考卷高解析對照**
   * 內建原卷第 1 頁與第 2 頁的高解析掃描圖，隨時查看老師批改與紅筆筆記。

## 🚀 如何啟動

* **方式一（最快）**：直接雙擊資料夾內的 `點我啟動學習網站.bat`。
* **方式二**：直接用瀏覽器（Chrome、Edge、Safari 等）開啟 `index.html`。
* **方式三**：若本機伺服器已開啟，可直接瀏覽 `http://localhost:8080`。
